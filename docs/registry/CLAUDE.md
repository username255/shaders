# Registry - Example Components

## Purpose
Self-contained examples for each shader.
Used in documentation and copy-paste snippets.

## File Pattern
`[shader-name]-example.tsx`

## Structure
Each example includes:
- Import statements
- Component with default props
- Common use cases
- Leva controls integration

## Usage
Referenced by `registry.json` for:
- Documentation generation
- Code examples
- Interactive demos

## Adding New Example
1. Create `[shader-name]-example.tsx`
2. Import shader component
3. Set up Leva controls
4. Add to `registry.json`
