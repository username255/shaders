# App Directory - Shader Demos

## Structure
Each shader has its own route:
- `layout.tsx` - Metadata & layout wrapper
- `page.tsx` - Demo with Leva controls

## Available Routes

### Gradient Shaders
- `/mesh-gradient` - Animated mesh
- `/grain-gradient` - Textured gradients
- `/static-mesh-gradient` - Static mesh
- `/static-radial-gradient` - Radial

### Pattern Shaders
- `/dot-grid` - Dot grid pattern
- `/dot-orbit` - Orbiting dots
- `/voronoi` - Voronoi cells
- `/spiral` - Spiral animation
- `/color-panels` - Color blocks

### Effect Shaders
- `/water` - Water simulation
- `/waves` - Wave patterns
- `/liquid-metal` - Metallic fluid
- `/god-rays` - Light rays
- `/metaballs` - Blob effects
- `/smoke-ring` - Smoke animation

### Noise Shaders
- `/perlin-noise` - Perlin noise
- `/simplex-noise` - Simplex noise
- `/neuro-noise` - Neural patterns
- `/paper-texture` - Paper effect

### Distortion Shaders
- `/swirl` - Vortex effect
- `/warp` - Space warping
- `/fluted-glass` - Glass distortion

### Special Shaders
- `/dithering` - Dithering patterns
- `/image-dithering` - Image processing
- `/pulsing-border` - Animated borders

## Demo Features
- Live parameter adjustment
- Export settings
- Responsive preview
- Code examples
